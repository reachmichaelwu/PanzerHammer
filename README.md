# PanzerHammer

A turn-based hex battle in the style of Panzer Marshal, played with Horus Heresy units. One scenario ships with the game: **The Iron Gate**, Imperial Fists (VII) against Iron Warriors (IV).

This repository is the game itself. It does not include the Warhammer30K Cognitor army builder. Unit numbers in `catalog.js` were generated from that project's public data files. The formulas below are the PanzerHammer conversion. They are not the Horus Heresy tabletop rules.

## Play

You command the Imperial Fists. Gold tokens are yours. Rust tokens are the Iron Warriors.

Select one of your units. Green hexes are legal moves. Red hexes are enemies that unit can attack. A unit may move once and then attack once. Heavy and ordnance weapons strike less accurately after moving. End the turn and the Iron Warriors reply.

Walls and chem-drains block movement. Vehicles cannot enter thorn scrub or bastions. Standing next to an enemy ends the move. Curtain walls and thorn scrub block shooting. The road through the Iron Gate does not. Stand on a strongpoint to take it. An empty strongpoint keeps its last owner.

**Restart** keeps the same combat seed. **New seed** rerolls damage. **Help** and **Unit codex** are in the side panel.

Victory: destroy every Iron Warriors unit, hold all three strongpoints after their reply, or hold at least two when turn 10 ends. Defeat: lose every Imperial Fists unit, or finish turn 10 holding fewer than two strongpoints.

## Run locally

The page is static. Open `index.html` directly (double-click it, or use a `file://` URL). The built-in battle is `scenarios/iron-gate.js`, loaded with a script tag, because browsers block `fetch()` of a local JSON file from `file://`.

A static server works the same way. From this directory:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000/](http://localhost:8000/).

`scenarios/iron-gate.json` is the same scenario for the **Import map** button and for tests. Import reads the file you pick. It does not fetch it. Two JSON formats are accepted:

- `panzerhammer-scenario-v1` — a map plus an `order` array of `{ instanceId, catalogId, side, col, row }`.
- `panzerhammer-map-v1` — terrain, size, and objectives. Current units are redeployed onto the same coordinates when every hex is still legal. See `normalizeMap` in `engine.js`.

Terrain letters in a row string: `.` clear, `r` road, `b` rubble, `t` woods, `f` fort, `w` wall, `g` gate, `u` water, `n` trench. Walls and water block everyone. Vehicles cannot enter woods or bastions.

## Where the units come from

`catalog.js` is a generated snapshot. Regenerating it is optional. The committed file is what the game and the tests use.

Portraits and banners are the files the catalog and The Iron Gate actually reference, copied from the public Warhammer30K repo into `artwork/` and `legions/`. This game does not add a license for that art. Paths in the catalog are relative to this repo (`artwork/Champion.jpg`, `legions/Imperialfist.jpg`).

| Piece | Warhammer30K file the generator reads |
| --- | --- |
| Names, model counts, categories | `02-unit-presets.js` |
| Points | `04-points.js` |
| Characteristics | `27-new-recruit-stats-data.js` (`NEW_RECRUIT_UNIT_STATS`), pinned from BSData horus-heresy-3rd-edition. See `new-recruit-stats-reference.json` in that checkout. |
| Representative shooting weapon | First shooting row in `05-weapon-profiles.js` `LEGION_WEAPON_PROFILES`, otherwise `07-army-builder-data.js` `WEAPON_PROFILES`. Names containing Maximal, Frag, or Fury of the Legion are skipped when another row exists. |
| Range | Matching armoury entry in `15-main-app.js` when the builder can see one; otherwise `getWeaponRangeInfo` in `05-weapon-profiles.js`. |
| Melee name, WS, S, A, AP | First row in `12-charge.js` `MELEE_WEAPON_PROFILES`. |
| Portraits | Paths already listed in that repo's `17-artwork.js` and `legions/`. |

Sigismund, Fafnir Rann, Alexis Polux, and the Warsmith have no shooting row of their own. The catalog flags a Bolt Pistol copied from the Despoiler Squad profile (`WEAPON_PROFILES.despoiler`) and says so in the codex.

The enemy Rapier is the Solar Auxilia Rapier Carrier, used here as an allied battery. Its codex name is the preset name, Auxilia Rapier Section.

The codex also lists Templar Brethren, Fafnir Rann, Alexis Polux, a Sicaran, and a Centurion so later scenarios can add them without a new data pass. They are not deployed in The Iron Gate. Their portraits are included because the catalog names them.

### Rebuild the catalog (optional)

Point the tool at a Warhammer30K checkout. It only reads that tree and writes `catalog.js` here:

```bash
node tools/build-catalog.js --source /path/to/Warhammer30K
```

`WARHAMMER30K_ROOT` works in place of `--source`. `--out` overrides the output path.

## Conversion used in play

- **Move:** `max(2, round(M / 2.5))` hexes. If the model type contains "Heavy", subtract 1, still at least 2. Tactical Squads (M7) move 3. Breachers and Phalanx Warders (Heavy) move 2. Predators (M12) move 5.
- **Hit points:** vehicles use listed HP. A single model uses W. A squad uses models × W. A Tactical Squad is 10 HP because the preset is 10 models at W1.
- **Range:** `max(1, round(inches / 8))` hexes. Template weapons are 1 hex. A 24" bolter is 3 hexes. A 48" lascannon is 6.
- **Ranged score:** shots + S + floor(BS / 2) + Damage. Heavy, Ordnance, and Barrage weapons lose 3 after the unit moves.
- **Melee score:** the charge-table WS + A + floor(S / 2). If that row is missing, the model's own WS, A, and S are used.
- **Defense:** infantry and walkers use T + a save bonus (2+ is +3, 3+ is +2, 4+ is +1) + 1 if an invulnerable save is listed, plus terrain cover. Vehicles use front armour − 5, plus half the cover, rounded down.
- **Cover:** rubble +1, thorn scrub and trenches +2, the gate +2, bastions +3.
- **Damage:** 2d6 + score − defense. 14+ deals 4, 11+ deals 3, 8+ deals 2, 5+ deals 1.
- **Armour facing:** against a vehicle, S at or above front armour keeps that damage; S within 4 of front armour loses 1 damage (minimum 1); S within 8 glances for 1; weaker shots do not wound. A bolter does not wound a Predator (front 13). A lascannon does.
- **Saves:** a non-vehicle save of the listed value or higher on 1d6 reduces damage by 1. Armour saves are ignored when a numeric AP is less than or equal to the save, which is the old "AP beats that save" shortcut, not the 3rd-edition damage-mitigation procedure. Invulnerable saves are not ignored. Vehicles do not take that save.
- **Zones of control:** entering a hex next to an enemy ends the move. A unit that starts next to an enemy must leave contact before it can move elsewhere.
- **Line of sight:** curtain walls, thorn scrub, and other units block the hexes between shooter and target.

## Extending

Add a unit id to `IDS` in `tools/build-catalog.js`, point `--source` at Warhammer30K, and regenerate. Add another `panzerhammer-scenario-v1` file and import it, or load it the way `scenarios/iron-gate.js` is loaded. The engine API used by tests is `createGame`, `legalMoves`, `legalAttacks`, `moveUnit`, `attackUnit`, `endPlayerTurn`, and `finishAiPhase`. The opponent lives in `ai.js`.

## Limitations

- One scenario, one simple opponent, no campaigns, supply, experience, or transport.
- One representative weapon per unit, not the wargear options in an army builder.
- Flyers are rejected at deployment.
- Combat is a single opposed roll, not the full shooting and vehicle-damage tables.
- The map is an original placeholder. See the license table above.
